# Opening mechanism: prospective census and gate contract

This is a separate experiment. No new dynamics or static Gate 2 targets. The native physical proposal picks a uniform site and one of six uniform directions; each unoriented bond has probability 1/(3V), including unlike A–B and particle–vacancy swaps; same-species swaps do not change the recorded state. For initially occupied x, h is the total probability per proposal of an accepted incident unlike swap. O sums over **nonincident** unlike proposals e their acceptance-weighted positive change in h after hypothetically swapping e. The positive part is taken **after summing all six new and old incident probabilities for that e**. This is neither net drift, a waiting time, nor the exact two-proposal event probability. No continuum Metropolis tail in place of native 64-bit thresholds. See the independent stencil proof and qualification receipt before production.

**Descriptive data contract (locked before reductions).** L20, final-verification release, 16,384 native identities per beta, ten betas; original beta index 8 replaced, never pooled, by doubled-depth amendment. Require every immutable (seed,id) distinct, confirm archive digest, validate exact 8,192 TRAIN / 8,192 TEST against the existing roster, and count 6,000 occupied centers per parent. For each parent accumulate means of Vh and V²O, zero fractions and a fixed joint count histogram: exact zero, positive values separated at powers of two from 2^-128 through 2^7 inclusive. Report projections in coarser fixed bins; logarithms never used to distinguish exact zero. Report temperature trends with independent-parent errors and conditional opening distributions by instantaneous-mobility bin. No fitting on these summaries. 983,040,000 sites are not that many independent draws.

For 4,096 static Gate 2 reserve parents per beta, only these predeclared descriptive tallies may be computed, without extracting any Gate 2 targets, eligibility, source exteriors, hidden cavity states, or histories. Store only additive group counts/moments for reserve (no identity-linked observables). Own-directory outputs only. Never include this reserve in discovery, prediction or dynamics. Preserve and distinguish the prior fit/dev/assess/reserve metadata labels. Cold local histories are a separate population; phase C uses its own original whole-parent split and paired ages. The prior static 3.2/3.4 roster has no Gate 2 reserve there. Any warmer history linked to a reserve parent is ineligible. No assumption that all static samples have histories.

**Gates.** Archive-source checksums, lineage and independent full-energy + high-precision qualification precede production. The history analyst locks a single source-defined primary horizon, matching/support, packing comparison, paired-age parent inference and practical decision threshold before outcome comparison; target never tunes it. The numerical analyst locks a local stock/reference comparison before running it; stable reporting alone is not stable optimization. A compact initial-surroundings predictor is admissible only after both physical transfer and *unmodified training* numerical validity pass. Otherwise stop without paid work, library patches, new arms or physical exclusion. Never use numbers from a failed bound. No workspace/account metadata in outputs.
